# Raíz Urbana

Landing page responsiva desarrollada con React, Vite y Bootstrap para el programa comunitario Raíz Urbana.

## Funcionalidades

- Interfaz organizada en componentes funcionales.
- Navegación adaptable a dispositivos móviles.
- Formulario controlado mediante `useState`.
- Validaciones dinámicas y mensajes de error o éxito.
- Formato automático del número telefónico.
- Indicador de seguridad de contraseña.
- Diseño responsivo con Bootstrap y estilos personalizados.

## Ejecución local

```bash
npm install
npm run dev
```

## Verificación

```bash
npm test
npm run build
```
